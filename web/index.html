An open-source CLI that benchmarks language models across providers. Measure speed and quality on your own prompts, put agents through sandboxed tasks that are graded on what they actually did, and browse four published leaderboards in one table.

$ uvx llmbench

Also pipx run llmbench or pip install llmbench. Python 3.11+, MIT.

Source on GitHub ↗

What llmbench does

01

Measure

One prompt set, many models, four ways to score.

throughput
Time to first token, tokens/sec, inter-chunk and total latency, token usage.
quality_exact
Deterministic check against an expected value: exact, contains, or regex.
quality_judge
LLM-as-judge, a 1–10 score with one line of reasoning.
image_gen
Generation latency plus the saved PNGs, for side-by-side review.

Every run writes an HTML gallery and a queryable SQLite row.

02

Exercise

Five multi-step tasks in a sealed sandbox. The verdict is read from post-run state, so a model cannot talk its way to a pass.

  • file-refactor
  • api-orchestration
  • multi-step-research
  • recovery
  • long-horizon

Sandbox primitives

  • fake_fs
  • fake_http
  • fake_sql
  • fake_search
  • fake_shell
  • failure_injector

Each run saves a full trace: turns, tool calls, tokens, timing, cost, verdict.

03

Connect

Ten adapters, hosted and local. Adding one is roughly forty lines.

Hosted
Anthropic · OpenAI · Google Gemini · Moonshot
Local
Ollama · vLLM · LM Studio
Image
Black Forest Labs · OpenAI · Gemini
Custom
Any OpenAI-compatible base URL

Models and API keys are configured from the interactive TUI, not a config file.

Published leaderboards

Scores from HuggingFace Open LLM v2, LMArena, and Aider Polyglot, plus an offline snapshot, in one sortable table. Refreshed daily. These are published numbers, not measured by llmbench.
